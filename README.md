# Pulse

Оригинальный полнофункциональный веб-чат: аккаунты, пространства, текстовые каналы, личные сообщения, онлайн-статус и сообщения в реальном времени.

## Возможности

- Улучшенная регистрация: проверка пароля и подтверждение почты шестизначным кодом
- Вход с хешированием паролей и JWT-сессиями
- Собственные пространства, публичный каталог и коды приглашения
- Каналы внутри пространства
- Личные диалоги, поиск пользователей и заявки в друзья
- Realtime через Socket.IO: сообщения, присутствие, индикатор набора
- Ответы, редактирование, удаление сообщений и реакции
- Настройка статуса и цвета профиля
- Адаптивный тёмный интерфейс
- SQLite с WAL, Docker и конфигурация Render

## Локальный запуск

```bash
cp .env.example .env
# обязательно поменяйте JWT_SECRET в .env
npm install
npm start
```

Откройте `http://localhost:3000`. Для проверки общения зарегистрируйте два аккаунта в разных браузерах или в обычном и приватном окне.

## Публикация на Render

1. Создайте Git-репозиторий и загрузите в него папку проекта.
2. В Render выберите **New → Blueprint** и подключите репозиторий.
3. Render прочитает `render.yaml`, соберёт Docker-образ и создаст постоянный диск для SQLite.
4. После публикации откройте выданный HTTPS-адрес.

Для бесплатного теста можно удалить секцию `disk` из `render.yaml` и поставить `plan: free`, но база будет сбрасываться при пересоздании сервиса. Для постоянных данных нужен диск.

## Переменные окружения

- `PORT` — порт сервера, по умолчанию 3000
- `JWT_SECRET` — длинная случайная строка для подписи сессий
- `DATA_DIR` — каталог SQLite, по умолчанию `./data`
- `NODE_ENV=production`

## Архитектура

- `server.js` — Express API и Socket.IO
- `db.js` — SQLite-схема и подключение
- `public/` — клиент без сборщика
- `Dockerfile`, `render.yaml` — публикация

## Перед серьёзным публичным запуском

Добавьте подтверждение почты, восстановление пароля, модерацию/жалобы, резервные копии базы, пользовательские правила и объектное хранилище для вложений. Для очень большой нагрузки замените SQLite на PostgreSQL, а Socket.IO масштабируйте через Redis adapter.
